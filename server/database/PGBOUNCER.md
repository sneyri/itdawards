# Пул соединений PostgreSQL

Приложение использует `pg.Pool` с размером по умолчанию 10. Размер можно задать переменной `DB_POOL_MAX` в корневом `.env`:

```dotenv
DB_POOL_MAX=10
```

Значение больше 10 имеет смысл только при нескольких concurrently работающих процессах. На текущем VPS один Node-процесс, поэтому 10 достаточно.

Если в будущем появятся дополнительные потребители базы, можно поставить PgBouncer:

1. Скопируйте `pgbouncer.ini.example` в `/etc/pgbouncer/pgbouncer.ini`.
2. Заполните `/etc/pgbouncer/userlist.txt` теми же учётными данными, что и в `.env`.
3. Запустите `systemctl enable --now pgbouncer`.
4. В `.env` замените `DB_PORT=5433` на `DB_PORT=6432`.

После смены порта перезапустите сайт и проверьте логи. PgBouncer не меняет данные и не требует миграций — это только прослойка между приложением и PostgreSQL.
