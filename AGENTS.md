# Проверки ITD Awards

- Начинайте с `README.md`, скриптов в `client/package.json` и `server/package.json` и нужных маршрутов.
- На Windows используйте `npm.cmd`. Проверки клиента запускаются командами `npm.cmd run build --prefix client` и `npm.cmd run lint --prefix client`.
- Для HTTP-тестов задайте `ITD_TEST_DATABASE_URL` с адресом `127.0.0.1` и именем отдельной базы, оканчивающимся на `_test`. Запустите `npm.cmd test --prefix server`. Тесты используют отдельные временные схемы и не загружают `server/.env`.
- Сценарии Telegram из `bot/` проверяйте с моками API. Тестовый стенд бота задаёт `ITD_BOT_TEST=1`, поэтому конфигурация приложения не загружается, и использует временную SQLite. Проверки браузера проводите в отдельном профиле. Команды для бота и сквозного теста перечислены в README.
